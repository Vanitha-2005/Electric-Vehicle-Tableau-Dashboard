# Electric Vehicle Tableau Dashboard

## Project Overview
This project analyzes Electric Vehicle (EV) population data using Tableau to understand EV adoption and distribution.

## Tools Used
- Tableau
- Microsoft Excel

## Dataset
Electric Vehicle Population dataset.

## Key Analysis
- Electric vehicle distribution
- Battery electric and plug-in hybrid vehicles
- Vehicle model and make analysis
- Model year trends
- Geographic distribution of EVs

## Project Files
- Tableau dashboard file (.twb)
- Raw dataset (.xlsx)
- Dashboard screenshot (.png)

## Objective
To explore electric vehicle population data and identify useful trends through interactive data visualization.

## Conclusion
This project presents EV population data in a visual format to support easier analysis and understanding.
